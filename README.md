# Avi Glyn — 3D Artist Portfolio

An animated, responsive portfolio for Avi Glyn’s character, creature and game-art journey.

## Features

- Interactive generative hero sculpture
- Live learning clock from 28 June 2026
- Animated project studies and competition roadmap
- Responsive motion system with reduced-motion support
- Static HTML, CSS and JavaScript suitable for Cloudflare Pages

Open `index.html` directly, or serve the directory with any static server.
